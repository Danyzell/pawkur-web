# pawkur.cz

Úvodní stránka aplikace Pawkur (plánovač agility a hoopers parkurů). Statický web na GitHub Pages s vlastní doménou (soubor `CNAME`).
Aplikace sama běží v repozitáři [Agility-trasa](https://github.com/Danyzell/Agility-trasa) na https://danyzell.github.io/Agility-trasa/.
Zdroj stránky je `web/index.html` v repozitáři aplikace; sem se kopíruje s absolutními odkazy do aplikace.
